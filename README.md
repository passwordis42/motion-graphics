# 修改合集

首页按原片时间展示序号、问题、修改方案和替换范围。点击「对比片段」可以同步播放原片与修改后的画面。

[打开修改合集](https://passwordis42.github.io/motion-graphics/)

## 添加片段

1. 在 `animations/` 下创建目录，放入 `index.html`、预览图和对应范围的无声 `original.mp4`。修改后的画面可用 Canvas 绘制，也可指定无声视频文件。使用 `animations/shared/` 中的播放器同步控制两侧画面。
2. 按原片时间顺序在首页添加一项，填写序号、原片时间戳、替换范围和标题，并用相对路径链接对应文件。
3. 通过本地静态服务器打开首页，确认预览、播放和下载链接有效。
