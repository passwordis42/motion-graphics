# 修改合集

每个修改片段都有独立的 HTML 播放页。首页按原片时间顺序展示片段序号、修改点、替换范围、预览图和可用的 MP4 下载。打开片段后，点击播放即可收听与字幕对应的中文旁白。

[打开修改合集](https://passwordis42.github.io/motion-graphics/)

## 添加片段

1. 在 `animations/` 下创建目录，放入 `index.html`、预览图、旁白 `narration.mp3` 和可选的 MP4。可用 `animations/shared/` 中的播放器提供播放、暂停和拖动进度。
2. 按原片时间顺序在首页添加一项，填写序号、原片时间戳、替换范围和标题，并用相对路径链接对应文件。
3. 通过本地静态服务器打开首页，确认预览、播放和下载链接有效。
